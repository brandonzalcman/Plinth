# Plinth 0.1.0

The first public release of Plinth: a native macOS browser with one floating bar instead of tabs.

## Highlights

- **The bottom bar.** Open pages are listed by name and grouped by website. Drag to reorder them, or drop one page on another to split.
- **Adaptive fading.** Sites you stop using fade out and drop onto a searchable shelf.
- **Pinned sites, split view and peek** (⇧-click a link), plus a mini window for links opened from other apps.
- **On-device AI** with Apple Intelligence: resume cards, ask page / ask site (⌘J) and search history by meaning. One switch turns it all off.
- **Group suggestions** for sites you keep open together.
- **Built-in content blocking**, a downloads indicator, find in page and zoom.
- **Automatic updates.** This version and later ones update themselves.

Requires macOS 26. The AI features need a Mac with Apple Intelligence turned on.
