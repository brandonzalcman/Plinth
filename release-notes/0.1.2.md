# Plinth 0.1.2

A small release: the download now says which version it is, and so does Settings.

## Highlights

- **Versioned downloads.** The disk image is now named after its version, for example `Plinth-0.1.2.dmg`, so you can tell downloads apart. The usual download link still always gets the newest version.
- **Version in Settings.** Plinth › Settings… › General has an About section showing the version and build number, with **Check for Updates…** next to it.

Requires macOS 26. The AI features need a Mac with Apple Intelligence turned on.
